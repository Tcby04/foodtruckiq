## Cities (Fayetteville to Bella Vista corridor)

### Core Cities
1. **Fayetteville** - 95k, University of Arkansas, downtown scene
2. **Springdale** - 81k, 2nd largest, diverse
3. **Rogers** - 70k, growing fast, retail hub
4. **Bentonville** - 60k, Walmart HQ, art scene (Crystal Bridges)
5. **Bella Vista** - 30k, retirement/resort community

## Data Points to Collect

| Category | Data |
|----------|------|
| **Location** | Name, address, lat/long, neighborhood |
| **Foot Traffic** | Daily est., peak hours, days |
| **Competition** | Food truck count, restaurant density, cuisine types |
| **Events** | Farmers markets, festivals, concerts, sports |
| **Regulations** | Permit process, fees, restrictions, zones |
| **Parking** | Street parking, lots, loading zones |
| **Demographics** | Population in radius, income level |
| **Amenities** | Restrooms, shade, power, water access |
